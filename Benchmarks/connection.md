# Connection lifecycle measurements

Run `swift run -c release ThrushBench --connection` from the repository root with the full Xcode toolchain and Bun on the path. The command builds the matching Release loopback client, prints p50 and p95 in milliseconds, and writes `.build/benchmarks/connection.json`. Use `--output PATH` to retain another run.

The workload starts a Bun WebSocket peer on the Mac’s loopback interface and connects two URLSession hosts using the same shell ID. Six attachments cover a fresh shell, a brief detach and foreground return, takeover by the second host, user-initiated reclaim, orphan expiry and a fresh shell after explicit close. The final shell sends its last two output frames before exit. The initial 16 × 3 grid makes a single row of history observable on resume. The first host sends one 18 × 3 resize and the foreground attachment returns to 16 × 3. During reclaim the host coalesces two requests into a single 17 × 3 resize after replay. Both sides check the exchange in every pass.

The peer runs the same script as `scripts/check-loopback.sh`. Its replay frames come from Toy Box’s xterm 6.0.0 scrollback buffer and addon-serialize 0.14.0. The preserved normal screen contains one history row and three visible rows. The alternate screen and application cursor mode survive takeover, including output that appeared before the new owner connected. [Toy Box replay implementation](https://github.com/lostintangent/toy-box/blob/b9d0eca3c5f4e9036e58327ba633eff52474bb92/src/features/terminal/server/scrollback.ts)

The first complete exchange is a warmup. Five measured passes each launch a fresh peer and client. A single monotonic peer clock, `Bun.nanoseconds()`, brackets each named interval. For example, “Foreground ready and replay to Up” begins immediately before queuing ready, serialized replay and live output. It ends when the peer handles the client’s binary Up key. These intervals include local transport, scheduling, adapter work and the client’s screen checks. The detach and exit intervals end at the peer’s WebSocket close callback. Connection setup, process startup and compilation fall outside the intervals.

The peer advances an independent virtual clock to test the 30-second orphan deadline immediately before and at expiry. The post-expiry measurement begins when the fresh ready frame is sent. The reclaimed replay interval begins when the peer releases the held replay frame. Both exclude test-driver waits for those events.

The JSON records each interval’s five samples in nanoseconds, nearest-rank p50 and p95, the peer script’s SHA-256 and the host environment. Five samples make p95 the slowest measured sample. The report describes scripted, headless macOS loopback. Presentation and physical iPhone measurements have separate workloads. CI checks wire and screen correctness independently of elapsed time.
